# Forever 钓鱼助手 v1.1.0

将钓鱼循环改为金色齿轮与声音驱动：齿轮不存在就抛竿，存在就等待，咬钩声音命中后立即按拾取 / 起杆键；默认 30 秒没有咬钩声音就直接重新抛竿，即使齿轮仍存在。

- 开始和暂停恢复时先检查齿轮，已有浮漂就接着等待。
- 移除水花画面检测、局部运动确认、声音候选等待、反应延迟和跳过咬钩。
- 30 秒从实际抛竿完成后计时，包含落水时间；起杆后重新计时。超时同轮收到声音时优先起杆。
- 保留上游 1.5 秒落水等待、图标尺度校准和金色过滤。齿轮丢失使用 1 秒防抖，避免打断正在完成的声音识别。
- 简化设置页，保留图标匹配、音频阈值和手动识别范围；声音图表显示最近 30 秒。
- 旧画面确认、拾取确认和反应设置自动忽略，原文件的注释与自定义值保留。`run.cast_timeout_s` 继续有效，默认 30 秒。
- 与 Rust 2.0.0-alpha.3 对齐，重新核对上游最新提交 `97653ba0`，无新增上游差异。

本地 Python 114 项、Rust 44 项回归全部通过，覆盖四段内置音频到起杆按键的完整链路、20 毫秒音频、图标闪烁和 30 秒超时边界；中文界面自检通过。Windows 发布流程执行原生构建、生成 EXE 的自检与 SHA256 校验，再发布图形版、命令行版和便携 ZIP。收杆计数仍是估计值，实际游戏联调需要对应客户端环境。

完整规则见 [简化钓鱼设计](../简化钓鱼设计.md)。
