Rust 原生桌面预览版更新，面向 Windows 10 / 11 64 位。

**运行 `ForeverFishing-Rust.exe` 无需安装 Python。** 便携 ZIP 包含 GUI、可选 CLI、中文使用说明、MIT 许可证、字体许可证和构建信息。

- 在实际抛竿后等待 1.5 秒再识别和自动校准，并核对抛竿前画面，减少落水动画和既有浮漂的干扰。缓存尺寸路径也执行核对，定位完成后释放抛竿前截图。
- 对齐 Python 的画面确认回退：连续两竿因画面确认拦截水花而没有收杆后，本次运行依据声音收杆并提示日志；再次开始恢复设置中的选项，不修改配置。修正中间无水花、等待候选期间超时的连续计数。
- 音频积压严格限制为最新 4 秒样本，支持部分包裁剪和单个大包。重连或丢弃积压后重置识别器、局部画面和旧咬钩候选，避免不连续音频触发旧结果。
- 只有实际发送的抛竿才增加计数。游戏失去前台或用户暂停导致按键取消时，进入暂停并清除成功提示；抛竿、补饵、跳跃和退出等待从按键发送完成后计算。
- 浮漂预览旁增加镜头与缩放提示，完善两版共用的上游差异跟踪和采用记录。

发布前本地通过 42 项 Rust release 测试、Python 音频参考值对照、严格 Clippy，以及 Linux 原生 GUI 的 15 张界面自检。Windows MSVC 目标的源码检查通过；Rust Native 工作流还会验证 Rust 1.88 最低编译器，在 Windows 原生构建并运行生成的 EXE 后打包，发布前核对 SHA256 和版本信息。

此版本继续作为预览版，Python v1.0.3 为正式版。进程音频要求 Windows Build 20348+，常见 Windows 10 可回退到系统回环。实际 Forever 客户端钓鱼仍需在你的环境中验证；收杆计数为图标消失后的估计。完整记录见 [持续优化记录](https://github.com/hellomrli/forever-fishing-zh/blob/rust-v2.0.0-alpha.2/docs/持续优化.md)。
