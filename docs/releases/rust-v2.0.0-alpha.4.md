# Forever 钓鱼助手 Rust 2.0.0-alpha.4

修复起杆后不能及时接着抛竿的问题，与 Python v1.1.1 对齐：实际起杆按键发送完成后等待 0.5 秒完成自动拾取，然后开始下一竿。

- 起杆后不再因残留齿轮重新等待 30 秒，也不叠加齿轮消失确认或随机抛竿间隔。
- 拾取阶段停止处理重复咬钩声音，到期无需再等截图；无法确认齿轮消失也会及时继续钓鱼，不计为漏检。
- 旧 `run.pause_min_s` / `run.pause_max_s` 保留，用于齿轮漏检后的重试，不会延迟正常起杆后的下一竿。
- 拾取等待与下一竿的 30 秒无声音期限均从对应按键发送完成后计算。
- 保留补饵、可选定时休息、暂停、停止与焦点检查；会话时间已到时完成本次拾取后退出，不再抛竿。
- 界面显示起杆后继续抛竿的规则，间隔设置改称“漏检重试间隔”。

继续作为 Rust 原生预览版，提供 Windows 图形版、命令行版、便携 ZIP、构建信息与 SHA256 校验文件。流程回归覆盖齿轮残留、旧配置长间隔、重复声音、按键发送延迟、暂停及四段内置真实音频。

本地 Rust 51 项、Python 125 项回归全部通过，严格 Clippy 与两版原生界面自检通过。Windows 发布流程还会检查 Rust 1.88 最低版本、两平台回归、原生构建生成的 EXE 与发布资产 SHA256。

完整规则见 [简化钓鱼设计](https://github.com/hellomrli/forever-fishing-zh/blob/main/docs/简化钓鱼设计.md)。
