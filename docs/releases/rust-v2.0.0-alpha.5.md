# Forever 钓鱼助手 Rust 2.0.0-alpha.5

- 自动选择客户端时同时核对窗口标题和游戏进程名或窗口类，不再将标题带有「Forever」的浏览器当作游戏。改名的客户端可在设置中指定独有的窗口标题，并通过 PID 核对目标。
- 抛竿前跳跃概率设为 100% 时也只跳一次。落地后检查齿轮再决定是否抛竿，不再循环跳跃。
- 游戏设置校验失败或写入失败时，已生效的快捷键和窗口筛选保持不变；修正输入后可以重新保存。

此版本是 Rust 原生预览版，不替代 Python 正式版。Windows 10 / 11 x64 可直接运行 `ForeverFishing-Rust.exe`，或下载同时包含 GUI、命令行版、使用说明和许可证的便携 ZIP。旧配置无需迁移，下载后可用 `SHA256SUMS.txt` 校验。
