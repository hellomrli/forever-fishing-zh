- 画面确认改为检查浮漂附近变化最强的一小块区域。此前要求截图中约 5% 的面积同时变化，比图标还小的水花不会通过；合成画面中，现在占 1% 的水花即可通过，静止水面和浮漂轻微晃动不会触发。
- 连续 2 竿“听到水花、画面没有确认、最后没有收杆”后，本次运行自动改为听到水花就收杆，并在日志中提示；下次开始钓鱼时恢复为设置中的选项。
- 画面确认没有通过时，日志写出“画面变化 X，需要 Y”，便于调整画面变化阈值。
