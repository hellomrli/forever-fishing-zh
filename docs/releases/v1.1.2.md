# Forever 钓鱼助手 v1.1.2

- 无法确认所选游戏在前台时，助手暂停输入，退出宏也不会发送。切回游戏后先确认齿轮，保留已经抛出的浮漂。
- 截图或校准耗时跨过 30 秒无咬钩期限时，本轮直接重抛，不再因刚找到或丢失齿轮而多等一个漏检间隔。达到会话时限后不再开始新的一竿；配置了退出宏时仍可完成手中这一竿。
- 等待声音时优先匹配上次齿轮的位置；没有命中就在同一张截图上搜索整个选定水域。没有可能的金色像素时直接跳过模板匹配和校准。

Windows 10 / 11 x64 用户可以直接运行 `ForeverFishing.exe`，也可以下载含 GUI、命令行版和使用说明的便携 ZIP。无需安装 Python 或重置旧配置。`SHA256SUMS.txt` 用于校验下载，`BUILD_INFO.txt` 记录构建对应的源码提交。
