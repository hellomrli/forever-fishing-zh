# Forever 钓鱼助手 v1.1.1

修复听到咬钩声起杆后迟迟不接着抛竿的问题：原流程会因齿轮残留重新等待 30 秒，或在齿轮消失后叠加消失确认和随机间隔；现在起杆按键发送完成后只等待 0.5 秒完成自动拾取，然后接着抛竿。

- 拾取期间的残留齿轮和重复声音不再延长等待，到期直接开始下一竿。
- 正常起杆后不叠加 `run.pause_min_s` / `run.pause_max_s`，无需重置旧配置；这两个设置继续用于齿轮漏检后的重试。
- 0.5 秒从实际起杆按键发送完成后计算，下一竿从实际抛竿完成起独立计算 30 秒无咬钩声音期限。
- 暂停、停止、游戏失去焦点和会话时限继续生效；已有的补饵与可选定时休息仍在两竿之间执行。
- 声音命中仍在当前循环立即发送拾取键，无需水花检测。界面说明同步更新。

提供原生 Windows 图形版、命令行版、便携 ZIP、构建信息和 SHA256 校验文件。流程回归覆盖齿轮残留、旧配置长间隔、重复声音、按键发送延迟、暂停及四段内置真实音频。

Python 125 项、Rust 51 项回归在 Linux 与 Windows 均通过，Ruff、严格 Clippy 与两版原生界面自检通过。Windows 原生构建生成的 EXE 自检及下载后的 SHA256 校验均已完成。

完整规则见 [简化钓鱼设计](https://github.com/hellomrli/forever-fishing-zh/blob/main/docs/简化钓鱼设计.md)。
