Rust 原生桌面预览版，面向 Windows 10 / 11 64 位。

运行 `ForeverFishing-Rust.exe` 无需安装 Python。便携 ZIP 包含 GUI、可选 CLI、中文使用说明、MIT 许可证、字体许可证与构建信息。

- 使用 egui 中文界面，内置 Noto Sans SC 字体、金色齿轮图标和四段水花素材。
- 原生 Windows 窗口枚举、移动 / 缩放同步、最小化暂停、模拟单键与全局 F8 / F9 控制。
- WASAPI 游戏进程回环与系统回环；打开失败按配置回退，显示实际声音来源。音频资源由同一线程打开和释放。
- 钓鱼状态机使用可中断等待；补饵被暂停打断后重新使用。互动后要求图标连续消失，计数标为估计值。
- 支持图标校准、按窗口比例框选水面、局部画面确认、水花得分曲线、录音验证、离线 WAV 分析和日志导出。
- 任务切换等待旧设备关闭，再自动执行新请求；取消排队任务及界面关闭时释放设备，丢弃旧任务的延迟结果。
- 配置兼容现有 UTF-8 TOML，保存时保留注释、未知字段、精简配置和未修改值的格式，支持相对中文路径与备份恢复。
- 独立 Python 音频参考值校验 Rust 特征、指纹、四种水花峰值和阈值建议。GUI 自检覆盖 900×640、100% / 125% / 150% 字体与底部按钮。

Rust Native 工作流在 Linux / Windows 验证源码，在 Windows 原生构建并运行生成的 EXE，随后打包 ZIP 与 SHA256 校验文件。Rust 预览标签使用 `rust-v2.0.0-alpha.1`，现有 Python v1.0.1 使用独立发布流程。

实际 Forever 客户端钓鱼联调仍需完成。进程音频接口要求 Windows Build 20348+，常见 Windows 10 可回退到系统回环。Linux 支持界面与离线分析，游戏捕获和输入由 Windows 后端实现。
