中文首版，面向 World of Warcraft: Forever，支持 Windows 10 / 11 64 位。

**普通用户下载 `ForeverFishing.exe` 即可运行，无需安装 Python。** 便携 ZIP 同时提供 GUI、可选 CLI、中文使用说明、许可证和构建信息。

- 完整中文“钓鱼 / 设置 / 校准与诊断”界面，支持小窗口和字体缩放。
- 修复中英文窗口识别、同名客户端选择、移动 / 缩放截图同步、单帧漏检误计数、配置覆盖与编码、空转、音频超时和试听错误显示。
- 增加浮漂画面核对、手动水面框选、F8 暂停 / 继续、F9 停止、可取消校准和录音任务。
- 实际探测游戏进程音频，失败时回退系统回环并显示原因；Windows 回环线程正确初始化 COM 并混音。
- 流式 WAV 录音、设备刷新、阈值建议、日志导出、配置备份恢复。

使用前在游戏中绑定抛竿和“与目标互动”键，开启自动拾取，并执行：

```text
/console SoftTargetIconGameObject 1
```

点击“开始钓鱼”后切回游戏窗口。切出或最小化游戏会自动暂停，恢复时重新抛竿。

发布文件经 Windows 原生构建，回归测试和**生成 EXE 的真实界面自检**通过后才发布。自检覆盖中文页面、配置、图片路径、快捷键以及测试窗口移动、缩放、最小化和恢复。
真实 Forever 客户端中的钓鱼尚未联调；收杆计数是图标连续消失后的估计。

进程音频要求 Windows Build 20348+；常见 Windows 10 系统使用回环模式。EXE 未做 Authenticode 签名，可用 `SHA256SUMS.txt` 校验下载文件。
