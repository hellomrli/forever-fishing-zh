浮漂识别与连续失败修复，支持 Windows 10 / 11 64 位。

**下载 `ForeverFishing.exe` 即可运行，无需安装 Python。** 便携 ZIP 包含 GUI、可选 CLI、中文使用说明、许可证和构建信息。

- 参考上游 v1.3.0，在实际抛竿后等待 1.5 秒让浮漂落水，再开始图标识别和自动校准，减少抛竿动画干扰。
- 核对抛竿前画面，忽略相同位置和尺寸的既有金色齿轮；已缓存图标尺寸时也执行核对，减少附近浮漂误匹配。找到浮漂、超时或暂停后释放整帧缓存。
- 修正画面确认失败的连续计数：中间没有听到水花的一竿会清除连续记录，画面候选等待期间本竿超时也会计入拦截。连续两次被画面确认拦截后，仍按既有行为在本次运行中回退到依据声音收杆。
- 浮漂预览旁提示保持游戏镜头和缩放不变，寻找状态说明正在等待浮漂落水。
- Linux PipeWire 支持从客户端对象继承进程 PID；多客户端优先绑定目标进程及其子进程，避免选到其他同名客户端的声音。
- 增加每日上游差异报告和采用记录，Python CI 同时覆盖主分支与 Rust 开发分支。

发布前本地通过 101 项 Python 回归测试、Ruff 检查，以及 Linux 真实 Tk 界面在 100% / 125% / 150% 字体缩放下的自检。发布流程在 Windows 原生构建后运行生成 EXE 的界面、窗口、截图和快捷键自检，再生成便携包与 `SHA256SUMS.txt`。

首次使用请绑定抛竿与“与目标互动”键、开启自动拾取，并执行 `/console SoftTargetIconGameObject 1`。默认 F8 暂停 / 继续、F9 停止。进程音频接口要求 Windows Build 20348+，常见 Windows 10 可使用系统回环。

实际 Forever 客户端钓鱼仍需在你的环境中验证；收杆计数为图标消失后的估计。完整改进与验证记录见 [持续优化记录](https://github.com/hellomrli/forever-fishing-zh/blob/v1.0.3/docs/持续优化.md)。
